# Plan 2.1: Per-Agent FastMCP Server & Client Session Builder

## Objective
Implement tool scoping and process isolation using the official `mcp` Python SDK (`FastMCP`), creating agent-specific MCP servers that expose ONLY the tools assigned to that agent's skill from `atlas`, pinned strictly to the agent's private graph slice, along with an MCP client interface for invoking scoped tools.

## Context
- `.gsd/SPEC.md` (REQ-09: FastMCP Tool Isolation)
- `.gsd/phases/2/RESEARCH.md`
- `luna/tools/registry.py` (Central tool registry)
- `luna/graph/store.py` (GraphStore wrapper)
- `luna/graph/schema.py` (Naming conventions)
