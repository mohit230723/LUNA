# Plan 2.2: Sub-Graph Slice Extraction (k-Hop Neighborhoods)

## Objective
Implement sub-graph slice extraction logic that queries the synthetic `domain` graph to extract a k-hop neighborhood centered on suspect customer entities and clones that isolated subgraph into a dedicated private graph (`agent_<run>_<agent>`) in FalkorDB using parameterized Cypher.

## Context
- `.gsd/SPEC.md` (REQ-10: Sub-Graph Slice Extraction)
- `.gsd/phases/2/RESEARCH.md`
- `luna/graph/store.py` (GraphStore wrapper)
- `luna/graph/schema.py` (Graph naming helpers)
- `luna/domain/generate.py` (Synthetic dataset entities and relationships)

  <name>Implement Slice Extraction Engine</name>
  <files>luna/orchestrator/slice.py, luna/orchestrator/__init__.py</files>

    - Create `luna/orchestrator/slice.py` with `extract_subgraph_slice(store: GraphStore, source_graph: str, target_graph: str, seed_cids: list[str], k_hops: int = 2) -> dict`.
    - Retrieve all nodes within `k_hops` of `seed_cids`:
      Use parameterized query matching paths up to `k_hops` length.
      Extract node labels, properties, and CIDs.
    - Retrieve all relationships connecting the extracted nodes.
    - Write nodes and relationships into `target_graph`:
      Batch CREATE nodes with their preserved properties (e.g. `cid`, `name`, `amount`).
      Batch CREATE relationships between preserved nodes.
    - Return extraction summary metadata: `{"source_graph": source_graph, "target_graph": target_graph, "nodes_extracted": int, "edges_extracted": int, "seed_cids": list[str]}`.
