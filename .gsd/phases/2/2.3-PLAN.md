# Plan 2.3: Sub-Agent Execution Loop & Draft Findings

## Objective
Implement the autonomous sub-agent execution loop where an agent executes within its private graph slice using only its equipped FastMCP tools, analyzes graph structures, and emits structured draft `Finding` objects containing evidence CIDs and confidence ratings.

## Context
- `.gsd/SPEC.md` (REQ-11: Sub-Agent Execution Loop)
- `.gsd/phases/2/RESEARCH.md`
- `luna/mcp/client.py` (AgentMCPClient)
- `luna/llm/client.py` (LLMClient protocol)
- `luna/atlas/models.py` (Skill models and prompt fragments)

<task type="auto">
  <name>Implement SubAgent Execution Loop</name>
  <files>luna/agents/subagent.py, luna/agents/__init__.py, tests/test_subagent.py</files>
  <action>
    - Create `luna/agents/subagent.py` with `SubAgent` class:
      - `async def run(self) -> list[Finding]`:
        1. Query MCP tools to gather structural evidence (e.g. `shared_attribute_links` or `ask_graph`).
        2. Format prompt combining skill's `prompt_fragment`, tool observations, and target entity IDs.
        3. Call `self.llm_client.complete()` with JSON schema for findings.
        4. Parse returned JSON into `list[Finding]`.
        5. If LLM output fails or is empty, provide deterministic rule-based analysis fallback based on tool evidence so tests and offline runs never fail.
    - Write unit test suite in `tests/test_subagent.py`:
      1. Execute sub-agent equipped with `entity-linker` on fraud ring slice: returns `suspicious` finding with high confidence (>0.85) citing shared bank account and address CIDs.
      2. Execute sub-agent on decoy family slice: returns `benign` finding citing legitimate single-vehicle claims with benign family address.
      3. Verify that `evidence_cids` are populated in generated findings.
  </action>
  <verify>pytest tests/test_subagent.py</verify>
  <done>Sub-agents autonomously execute tools in their private slice and produce well-formed findings.</done>
</task>
