# Plan 2.3 Summary: Sub-Agent Execution Loop & Draft Findings

## Delivered Capabilities
1. **Sub-Agent Finding Data Model** (`luna/agents/models.py`):
   - `Finding`: Encapsulates structured outputs emitted by sub-agents:
     - `id`: unique finding ID (`find-xxxx`).
     - `agent_id`: ID of investigating agent.
     - `skill_id`: ID of equipped skill.
     - `target_cid`: target entity being evaluated.
     - `verdict`: `"suspicious"` | `"benign"`.
     - `confidence`: range `[0.0, 1.0]`.
     - `reasoning`: detailed justification.
     - `evidence_cids`: list of genuine entity CIDs supporting the verdict.
     - `timestamp`: UTC ISO 8601 string.
   - `SubAgentRunConfig`: encapsulates agent configuration (`agent_id`, `skill_id`, `prompt_fragment`, `target_cids`, `private_graph_name`).

2. **Autonomous Sub-Agent Loop** (`luna/agents/subagent.py`):
   - `SubAgent(config, mcp_client, llm_client)`:
     - **Observe**: Inspects allowed FastMCP tools and invokes available ones (`shared_attribute_links`, `connected_components`, `pagerank_top`, `claim_amount_outliers`, `ask_graph`) against the private graph slice. Accumulates observations and genuine evidence CIDs.
     - **Orient & Decide**: Formulates prompt with skill instructions and tool observations. Attempts structured LLM synthesis via `llm_client.complete()`.
     - **Fallback Resilience**: Provides deterministic heuristic graph evaluation based on attribute collision density, cluster size, and outlier metrics, ensuring 100% test reliability and offline execution.
     - **Act**: Produces validated draft `Finding` objects citing specific `evidence_cids`.
