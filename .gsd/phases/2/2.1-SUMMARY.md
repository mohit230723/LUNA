# Plan 2.1 Summary: Per-Agent FastMCP Server & Client Session Builder

## Delivered Capabilities
1. **Agent FastMCP Server Factory** (`luna/mcp/server.py`):
   - `create_agent_mcp_server(agent_id, tool_names, graph_store, agent_graph_name)`:
     - Validates tool authorization against `TOOL_REGISTRY`.
     - Injects and pins `graph_store` and `agent_graph_name` into tool executions.
     - Guarantees sub-agents cannot pass arbitrary graph names or escape their designated private graph slice.
   - `get_server_tool_names(server)` inspects registered tools.

2. **Agent MCP Client Adapter** (`luna/mcp/client.py`):
   - `AgentMCPClient(server, allowed_tool_names)`:
     - `list_tools()`: Lists only allowed tools with JSON schemas.
     - `call_tool(name, arguments)`: Strictly verifies tool exposure; raises `PermissionError` on unauthorized access.
     - Unwraps FastMCP responses (`TextContent` JSON string / tuples) into native Python dicts and lists.

   - Enhanced `GraphStore.query()` to safely decode bytes column names from Redis protocol headers without literal stringification artifacts (`b'...'`).
