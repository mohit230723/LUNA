# Plan 3.3: Action Proposal, Approval Barrier, Idempotent Execution & Evaluation

## Objective
Implement action proposal generation, an inviolable human approval barrier, idempotent domain graph mutations, and ground truth evaluation against the synthetic fraud ring and decoy family.

## Context
- `.gsd/SPEC.md` (REQ-15: Human Approval Gate & Action Execution)
- `.gsd/phases/3/RESEARCH.md` (Section 3: Action Lifecycle)
- `docs/fixes_report.md` (Mandatory Rule: `execute_action` refuses execution unless Action status is `APPROVED`)

## Tasks

<task type="auto">
  <name>Implement Action Lifecycle Engine and Human Approval Gate</name>
  <files>luna/orchestrator/actions.py, luna/orchestrator/__init__.py</files>
  <action>
    - Create `luna/orchestrator/actions.py` with:
      - Models: `Action`, `Outcome`, `EvaluationMetrics`.
      - `propose_actions(store: GraphStore, run_graph_name: str) -> list[Action]`:
        - Scans `run_graph_name` for active decisions (or unchallenged findings) concluding `"suspicious"`.
        - Generates `(:Action)` node with `status = "PENDING"`, `action_type = "FLAG_CUSTOMER"`, `created_at = $timestamp`.
        - Links `(action)-[:BASED_ON]->(decision_or_finding)`.
      - `approve_action(store: GraphStore, run_graph_name: str, action_id: str, approver: str = "human") -> Action`:
        - Sets `action.status = 'APPROVED'`, `action.approver = $approver`, `action.approved_at = $timestamp`.
      - `reject_action(store: GraphStore, run_graph_name: str, action_id: str, approver: str = "human", reason: str = "") -> Action`:
        - Sets `action.status = 'REJECTED'`, `action.approver = $approver`, `action.rejection_reason = $reason`.
      - `execute_action(store: GraphStore, run_graph_name: str, domain_graph_name: str, action_id: str) -> Outcome`:
        - MANDATORY APPROVAL CHECK: Queries `action.status`. If status != 'APPROVED', raises `PermissionError(f"Action '{action_id}' cannot be executed: status is '{status}', requires 'APPROVED'")`. NO BYPASS FLAG.
        - If APPROVED:
          - Applies parameterized Cypher to `domain_graph_name`:
            `MATCH (c:Customer {cid: $cid}) SET c.flagged = true, c.flagged_at = $timestamp`
          - Creates `(:Outcome)` in `run_graph_name`: `(action)-[:RESULTED_IN]->(outcome)`.
          - Sets `action.status = 'EXECUTED'`, `action.executed_at = $timestamp`.
      - `evaluate_outcomes(store: GraphStore, domain_graph_name: str, ground_truth: GroundTruth) -> EvaluationMetrics`:
        - Queries flagged customers in `domain_graph_name`.
        - Calculates TP (flagged ring members), FP (flagged non-ring members), TN (unflagged decoy members), FN (unflagged ring members).
        - Computes Precision, Recall, and F1 score.
  </action>
  <verify>pytest tests/test_actions.py</verify>
  <done>Action engine enforces approval gate, executes idempotent domain tagging, and computes ground truth metrics.</done>
</task>
