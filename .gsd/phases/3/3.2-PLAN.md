# Plan 3.2: Main-Agent Conflict Resolution

## Objective
Implement main-agent conflict resolution logic in `run_<id>` that evaluates conflicting findings, arbitrates based on confidence, evidence count, and skill historical scores, writes `Decision` nodes, creates `UPHELD` and `SUPERSEDES` links, and marks losing findings as `superseded` without deleting them.

## Context
- `.gsd/SPEC.md` (REQ-14: Conflict Resolution)
- `.gsd/phases/3/RESEARCH.md` (Section 2: Main-Agent Conflict Resolution)
- `docs/schema.md` (Frozen naming contract for `Decision`, `UPHELD`, `SUPERSEDES`)
- `luna/graph/schema.py` (`LABEL_DECISION`, `REL_UPHELD`, `REL_SUPERSEDES`)

<task type="auto">
  <name>Implement Main-Agent Conflict Resolver</name>
  <files>luna/orchestrator/resolve.py, luna/orchestrator/__init__.py</files>
  <action>
    - Create `luna/orchestrator/resolve.py` with:
      - Pydantic model `Decision`:
        - `id: str`
        - `target_cid: str`
        - `chosen_verdict: str`
        - `confidence: float`
        - `reasoning: str`
        - `winning_finding_id: str`
        - `superseded_finding_ids: list[str]`
        - `resolved_at: str`
      - `resolve_conflicts(store: GraphStore, run_graph_name: str, atlas_graph_name: str = "atlas", llm_client: Optional[LLMClient] = None) -> list[Decision]`:
        - Finds unresolved contradictions in `run_graph_name` where neither finding is yet superseded.
        - For each conflicting pair/group on `target_cid`:
          - Fetches finding details: `confidence`, `evidence_cids`, `skill_id`, `reasoning`.
          - Queries `atlas` for skill score (`MATCH (s:Skill {id: $skill_id})-[r:SUCCEEDED_ON]->() RETURN r.score`).
          - Weighted arbitration score: `score = confidence * 0.5 + (len(evidence_cids) > 0 ? 0.3 : 0.0) + atlas_score * 0.2`.
          - Selects winner and losers.
          - Generates rationalization summary explaining why the winner was chosen.
          - Creates `(:Decision)` node in `run_graph_name`.
          - Sets `loser.status = 'superseded'` on losing findings.
          - Creates `(d)-[:UPHELD]->(winner)` and `(d)-[:SUPERSEDES]->(loser)`.
        - Export in `luna/orchestrator/__init__.py`.
  </action>
  <verify>pytest tests/test_resolve.py</verify>
  <done>Resolver marks losing findings superseded, links decision with UPHELD and SUPERSEDES, preserving complete audit history.</done>
</task>
