# Plan 3.1: Contradiction Detection Engine

## Objective
Implement automated contradiction detection identifying promoted findings in `run_<id>` that evaluate the same target entity with conflicting verdicts (e.g. `"suspicious"` vs `"benign"`), creating `[:CONFLICTS_WITH]` edges with detection timestamps.

## Context
- `.gsd/SPEC.md` (REQ-13: Contradiction Detection)
- `.gsd/phases/3/RESEARCH.md` (Section 1: Contradiction Detection)
- `docs/schema.md` (Frozen naming contract for `run_<id>` labels and edges)
- `luna/graph/schema.py` (`LABEL_FINDING`, `LABEL_CUSTOMER`, `REL_ASSESSES`, `REL_CONFLICTS_WITH`)
- `luna/graph/store.py` (`GraphStore`)

  <name>Implement Contradiction Detection Models and Graph Queries</name>
  <files>luna/orchestrator/conflicts.py, luna/orchestrator/__init__.py</files>
  <action>
    - Create `luna/orchestrator/conflicts.py` with:
      - Pydantic model `Contradiction`:
        - `finding1_id: str`
        - `finding2_id: str`
        - `target_cid: str`
        - `verdict1: str`
        - `verdict2: str`
        - `detected_at: str`
      - `detect_contradictions(store: GraphStore, run_graph_name: str) -> list[Contradiction]`:
        - Parameterized Cypher query matching:
          ```cypher
          MATCH (f1:Finding)-[:ASSESSES]->(c:Customer)<-[:ASSESSES]-(f2:Finding)
          WHERE f1.id < f2.id AND f1.verdict <> f2.verdict
          MERGE (f1)-[r:CONFLICTS_WITH]-(f2)
          ON CREATE SET r.detected_at = $detected_at
          RETURN f1.id AS f1_id, f2.id AS f2_id, c.cid AS target_cid, f1.verdict AS v1, f2.verdict AS v2, coalesce(r.detected_at, $detected_at) AS detected_at
          ```
        - Export `detect_contradictions` and `Contradiction` in `luna/orchestrator/__init__.py`.
  </action>
  <verify>pytest tests/test_conflicts.py</verify>
  <done>Contradiction engine detects opposing verdicts on same CID and links them with CONFLICTS_WITH edges.</done>
</task>
