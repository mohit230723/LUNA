# Plan 3.4: Cross-Run Learner in Atlas

## Objective
Implement cross-run skill score learning in `atlas` that adjusts `(:Skill)-[:SUCCEEDED_ON]->(:TaskType)` edge scores via Exponential Moving Average (EMA) based on action outcomes and decision resolutions, closing the feedback loop for future agent skill selections.

## Context
- `.gsd/SPEC.md` (REQ-16: Cross-Run Learning)
- `.gsd/phases/3/RESEARCH.md` (Section 4: Cross-Run Learning in Atlas)
- `docs/schema.md` (Frozen naming contract for `atlas` labels and edges)
- `luna/graph/schema.py` (`LABEL_SKILL`, `LABEL_TASK_TYPE`, `REL_SUCCEEDED_ON`)
- `luna/atlas/assign.py` (Skill selection using `SUCCEEDED_ON.score`)

<task type="auto">
  <name>Implement Atlas Cross-Run Learner</name>
  <files>luna/atlas/learner.py, luna/atlas/__init__.py</files>
  <action>
    - Create `luna/atlas/learner.py` with:
      - `update_skill_score(store: GraphStore, skill_id: str, task_type: str = "fraud_ring_investigation", reward: float = 1.0, alpha: float = 0.2, atlas_graph: str = "atlas") -> dict[str, Any]`:
        - Applies parameterized Cypher to `atlas_graph`:
          ```cypher
          MATCH (s:Skill {id: $skill_id})-[r:SUCCEEDED_ON]->(t:TaskType {name: $task_type})
          SET r.score = (1.0 - $alpha) * r.score + $alpha * $reward,
              r.runs = r.runs + 1,
              r.last_updated = $timestamp
          RETURN s.id AS skill_id, t.name AS task_type, r.score AS new_score, r.runs AS runs, r.last_updated AS last_updated
          ```
        - Handles fallback if relationship doesn't exist yet (creates it with default initial score).
      - `learn_from_run(store: GraphStore, run_graph_name: str, ground_truth: GroundTruth, atlas_graph: str = "atlas", alpha: float = 0.2) -> list[dict[str, Any]]`:
        - Analyzes all decisions and outcomes in `run_graph_name`.
        - For winning findings supporting true positives: rewards skill with `reward = 1.0`.
        - For superseded findings or false positives: penalizes skill with `reward = 0.0`.
        - Updates respective `SUCCEEDED_ON` edges in `atlas`.
        - Returns list of update records.
      - Export in `luna/atlas/__init__.py`.
  </action>
  <verify>pytest tests/test_learner.py</verify>
  <done>Atlas skill scores smoothly adapt based on run feedback via EMA.</done>
</task>
