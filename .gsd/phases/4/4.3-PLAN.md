# Plan 4.3: FastAPI Backend & SSE Streaming

## Objective
Implement `luna/api/app.py` providing a FastAPI backend server that exposes REST endpoints for starting runs, inspecting graph topologies, retrieving "Why?" explainability trees, controlling human approval gates, and streaming live execution events via Server-Sent Events (SSE).

## Context
- `.gsd/SPEC.md` (Goal 5: FastAPI Backend with SSE)
- `.gsd/REQUIREMENTS.md` (REQ-18: FastAPI Backend & SSE Streaming)
- `luna/orchestrator/pipeline.py` (`LunaPipeline`, `PipelineEvent`)
- `luna/orchestrator/explain.py` (`explain_action`, `explain_customer`)
- `luna/orchestrator/actions.py` (`approve_action`, `reject_action`, `execute_action`)

## Tasks

<task type="auto">
  <name>Implement FastAPI REST API & SSE Streaming</name>
  <files>luna/api/app.py, luna/api/__init__.py</files>
  <action>
    - Create `luna/api/app.py` with:
      - FastAPI app with CORS middleware enabled for Vite frontend (`localhost:5173`, `*`).
      - In-memory active runs dictionary (`dict[str, RunState]`) storing run status, pipeline instance, event queues, and results.
      - Endpoints:
        - `GET /health`: Health check returning status and FalkorDB connectivity.
        - `POST /api/runs`: Launch a new investigation run asynchronously in background task. Returns `{"run_id": str, "status": "started"}`.
        - `GET /api/runs/{run_id}`: Get run status, current step, actions, and evaluation metrics.
        - `GET /api/runs/{run_id}/events`: Server-Sent Events (`text/event-stream`) streaming `PipelineEvent` messages as they occur.
        - `POST /api/runs/{run_id}/actions/{action_id}/approve`: Human approval endpoint. Transitions action to APPROVED and triggers execution.
        - `POST /api/runs/{run_id}/actions/{action_id}/reject`: Reject proposed action with optional reason.
        - `GET /api/runs/{run_id}/why/{target_cid}`: Returns "Why?" explanation provenance graph and narrative for the given entity.
        - `GET /api/graphs/{graph_name}`: Returns nodes and edges formatted for Cytoscape.js visualization.
        - `GET /api/replay`: Returns recorded demo replay JSON for instant demonstration without live execution.
      - Export `create_app` and `app` in `luna/api/__init__.py`.
  </action>
  <verify>pytest tests/test_api.py</verify>
  <done>FastAPI server exposes full control surface and real-time SSE stream.</done>
</task>
