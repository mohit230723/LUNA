<task type="auto">
  <name>Deterministic Graph Algorithm Tools</name>
  <files>luna/tools/algorithms.py</files>
  <action>
    Implement the 5 deterministic graph analysis functions in `luna/tools/algorithms.py`:
    1. `shared_attribute_links(store: GraphStore, graph_name: str, cid: str, attr_types: list[str] | None = None) -> list[dict]`:
       Queries entities sharing phone, bank account, or address with `cid`.
    2. `connected_components(store: GraphStore, graph_name: str, cids: list[str], rel_types: list[str] | None = None) -> list[list[str]]`:
       Fetches sub-graph edges for `cids` and computes connected components using NetworkX `connected_components` algorithm for 100% reliable execution.
    3. `pagerank_top(store: GraphStore, graph_name: str, limit: int = 10) -> list[dict]`:
       Computes centrality/influence using parameterized Cypher degree centrality or NetworkX PageRank over graph edges.
    4. `shortest_path(store: GraphStore, graph_name: str, source_cid: str, target_cid: str) -> list[dict]`:
       Finds shortest path between two nodes using Cypher `shortestPath((a)-[*]-(b))`.
    5. `claim_amount_outliers(store: GraphStore, graph_name: str, std_dev_threshold: float = 2.0) -> list[dict]`:
       Calculates mean and standard deviation of claim amounts and returns claims exceeding the threshold.
    AVOID: Unparameterized queries; ensure all node CIDs and thresholds are passed via query parameters.
  </action>
  <verify>python -c "from luna.tools.algorithms import shared_attribute_links, connected_components; print('Algorithms imported')"</verify>
  <done>Algorithm tools compile and expose standardized signatures accepting store, graph_name, and parameters.</done>
</task>

<task type="auto">

  <files>luna/tools/ask_graph.py, luna/tools/registry.py, tests/test_tools.py</files>
  <action>

       - Test each algorithm against synthetic graph structures or mock `GraphStore`.

       - Verify `ask_graph` execution and error resilience.
